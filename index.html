06. Steps

Download to first board in a minute.

01

Download

Press the download button. Your browser may ask whether to keep stuff.exe. Choose Keep (Edge: "..." → Keep → Keep anyway; Chrome: the arrow → Keep).

02

Put it somewhere

Move stuff.exe to a folder you'll keep it in, for example Documents\stuff. It can update itself there, so pick a folder you can write to, not Program Files.

03

Run it

Double-click stuff.exe. The first time, Windows may show a blue warning. That is expected, see the next section. After you allow it once, it won't ask again.

04

Make a board

Drag files onto the window. Press Tab or click the scroll wheel for the tool wheel, / to ask Claude. It lives in the tray, so closing the window puts it away instead of quitting.

07. If Windows warns you

Why it warns, and how to get past it.

stuff is a small independent app and isn't code-signed yet (signing certificates are paid and sized for companies). Windows shows a warning for any program it hasn't seen many people run. It doesn't mean something is wrong, but you should only run it if you downloaded it from this page. Here is how to check, then run it.

A

Verify the file first

Compare your download with the SHA-256 shown in the download box above (or on the release page). In PowerShell, from the folder with the file:

Get-FileHash .\stuff.exe -Algorithm SHA256

If the two hashes are identical, it's the exact file that was published. If they differ, delete it and download again.

B

"Windows protected your PC" (SmartScreen)

  • Click More info (the small link under the message).
  • Click Run anyway.

If there is no Run anyway button: close the box, right-click stuff.exe → Properties → tick Unblock at the bottom → OK, then run it again.

C

Antivirus quarantined it or says "threat found"

Unsigned programs that are new and rare are sometimes flagged by mistake (a "false positive"). stuff is a single self-contained .exe, which some scanners treat with suspicion. If you checked the hash in step A and trust the source:

  • Windows Security → Virus & threat protection → Protection history → open the entry for stuff.exe → Actions → Allow on device.
  • Or add the folder you keep it in as an exclusion: Virus & threat protection → Manage settings → Exclusions → Add or remove exclusions → Add an exclusion → Folder.
  • Other antivirus: look for "quarantine", "restore" or "allow list", and restore the file, then allow it.

Only exclude the one folder that holds stuff.exe, never a whole drive. Help the rest of us too: report the false positive to your antivirus vendor (Microsoft takes submissions at microsoft.com/wdsi/filesubmission).

Want to be sure before running it? Upload stuff.exe to a multi-scanner such as VirusTotal and look at the result yourself.
